# Favorable-deal practice

Issue #175 adds `dealBias: off|light|strong` to the lobby and legacy `--deal-bias` option. Off is the default. Restart keeps setup; resume restores the stored mode and rejects an explicit mismatch. Never downgrade contract-bearing stores to a version that ignores selection provenance.

`weighted-holes-v1` selects from all 1,326 unordered user hole-card combinations. Pairs, suited aces, two broadways and suited connectors 65s or higher receive weights 1/2/4 in off/light/strong; every other combination has weight 1. Selected-card order is randomized, then the remaining 50 cards are uniformly shuffled. Opponent/board distribution is uniform conditional on the user's selected cards, not marginally identical to an unbiased game. There is no board lookahead or best-of-N selection. This does not guarantee winning or a favorable board.

Off takes the original shuffle path with exactly the same random draws. Non-off rejects explicit test decks. New configured sessions stamp a separate versioned `dealSelection` on every hand, including weak selections, and retain it through decisions, archive, replay, evaluation, summary and schema-7 profile events. This is not hint assistance. Historical events remain byte-preserved; profile projection remains schema 6 and accepts both historical and new event versions.

Canonical consumption compares config, archived hand, decision and evaluation markers. Removing provenance, relabeling strong as off or downgrading a new event against its canonical evaluation is rejected. Biased practice remains visible but contributes no independent score, mix distribution, leak/mistake entry, assessment/retest result or goal. The whole hand is excluded from the independent 60-hand self-model threshold, even with no user actions. Hint-enabled unbiased play is still independently excluded for hints.

Verification includes exact off deck/51-draw equivalence, 20,000 seeded deals per mode against exact weighted probabilities, 20,000 conditional remaining-card samples, unique cards/chip conservation at 2–9 seats, 59 independent + 100 biased hands staying at 59, canonical provenance stripping rejection, profile and mistake-bank persistence, and app setup/restart integration. Sampling tolerances are fixed tests (0.02 hole-class frequency; 0.008 conditional card frequency), not statistical evidence of poker performance.
